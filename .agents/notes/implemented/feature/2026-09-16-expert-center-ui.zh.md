# Agent Note：能力中心提供可用的已挂载专家目录

Status: implemented

[English](2026-09-16-expert-center-ui.md) | 中文

## 问题

侧栏入口只提供紧凑状态视图，用户无法浏览宿主实际挂载的专家，也无法查看专家绑定的阶段与工具。

## 决定

Web 入口在现有 Modal 生命周期内渲染能力中心。“专家”页把宿主快照中的 `ExpertTeamView.experts` 展平为卡片，支持按名称、角色、id 和团队元数据搜索，按已挂载团队筛选，并按宿主顺序或专家名称排序。选中卡片后展示所属团队、模式、绑定阶段、人工审核关口和声明工具；未选中详情时，目录使用全部可用宽度。能力中心还从同一快照展示当前进程最近六条运行记录。“技能”“连接器”和“记忆库”页面由各自 UI 包通过键控的根插槽独立贡献，详见[能力中心记录](2026-09-25-capability-center.zh.md)。能力中心对编排保持只读；卡片和详情操作通过单独的[新会话选择流程记录](2026-09-16-expert-center-summon.zh.md)交接。

## 备选方案

**在客户端编造技能或连接器记录。** 否决：空猜目录会与宿主不一致，并掩盖缺少能力数据源这一事实。

**从目录直接调用编排变更。** 否决：本包消费的是只读 Remote 视图，编排与关口仍由宿主/模型边界拥有。

**保留紧凑面板，只增加更多状态文字。** 否决：状态文字不能提供发现已挂载专家所需的浏览、搜索、筛选和详情能力。

## 结果

侧栏入口现在在能力中心中提供专家目录导航与发现流程，没有引入第二份事实源。目录对编排仍然只读，但召唤操作可以在普通空白对话中预填选定专家与提示；运行历史仍限于当前宿主进程。其他能力页面由各自所属的数据与 UI 包独立提供。

## 测试

能力中心聚焦测试覆盖专家目录、搜索、团队筛选、名称排序、专家详情、召唤操作、能力标签分发与后备状态、Remote 失败、关闭行为和键盘标签导航；选择测试覆盖异步空白会话交接与标签移除。当前实现的包级与 bundle 验证证据记录在[能力中心记录](2026-09-25-capability-center.zh.md)。
