# Agent Note：专家中心提供可用的已挂载专家目录

Status: implemented

[English](2026-09-16-expert-center-ui.md) | 中文

## 问题

侧栏入口只提供紧凑状态视图，用户无法浏览宿主实际挂载的专家，也无法查看专家绑定的阶段与工具。参考交互还预留了顶层的“技能”和“连接器”入口，而本包目前没有这两个领域的 Remote 数据源。

## 决定

Web 入口在现有 Modal 生命周期内渲染专家中心。“专家”页把宿主快照中的 `ExpertTeamView.experts` 展平为卡片，支持按名称、角色、id 和团队元数据搜索，按已挂载团队筛选，并按宿主顺序或专家名称排序。选中卡片后展示所属团队、模式、绑定阶段、人工审核关口和声明工具；未选中详情时，目录使用全部可用宽度。专家中心还从同一快照展示当前进程最近六条运行记录。在 Host 数据源建立前，“技能”和“连接器”作为可见入口显示明确的尚未接入说明。专家中心对编排保持只读；卡片和详情操作通过单独的[新会话选择流程记录](2026-09-16-expert-center-summon.zh.md)交接。

## 备选方案

**在客户端编造技能或连接器记录。** 否决：空猜目录会与宿主不一致，并掩盖缺少能力数据源这一事实。

**从目录直接调用编排变更。** 否决：本包消费的是只读 Remote 视图，编排与关口仍由宿主/模型边界拥有。

**保留紧凑面板，只增加更多状态文字。** 否决：状态文字不能提供发现已挂载专家所需的浏览、搜索、筛选和详情能力。

## 结果

侧栏入口现在提供目录导航与发现流程，同时没有引入第二份事实源。可见的占位入口让参考布局可以扩展，并明确当前集成边界。目录对编排仍然只读，但召唤操作可以在普通空白对话中预填选定专家与提示；运行历史仍限于当前宿主进程。未来的技能或连接器 Remote 视图可以填充现有入口。

## 测试

专家中心聚焦测试覆盖目录打开、搜索、团队筛选、名称排序、专家详情、召唤操作、未接入能力入口、Remote 失败和关闭行为；选择测试覆盖异步空白会话交接与标签移除。同时执行了 TypeScript 编译、客户端 UI i18n 校验、本包 bundle、Web 构建和 DevFrame 浏览器实时流程；实时快照显示两个已挂载团队、十五位专家、预填提示与专家选择标签。
