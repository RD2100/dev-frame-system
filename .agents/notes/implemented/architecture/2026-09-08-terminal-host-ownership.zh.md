# Agent Note: 宿主终端所有权独立于隔离实例的存续

Status: implemented

[English](2026-09-08-terminal-host-ownership.md) | 中文

## Problem

host 可见的单个终端服务无法枚举隔离服务实例持有的会话。空的提供者清单也无法阻止新挂载的服务在停止后启动终端。

## Decision

host 只挂载一次 `terminalOwnership`。每个终端服务在构造时登记，并在预留启动之前检查共享的确切 Agent 准入限制。排空先关闭入口，再等待所有已登记实例。服务成功销毁后才注销；清理失败会保留登记及未解决的活动。

批量恢复捕获目录成员及每个所有者的排空代次。提交先重新校验所有者与提供者就绪状态，再同步开放所有入口。这补充了[宿主停止适配器决策](2026-09-08-command-goal-binding-host-stop-adapters.zh.md)中独立承担职责的谱系和写入者规则。

## Alternatives considered

只查找一个 `ctx.terminals` 值会遗漏隔离实例。只登记已经启动终端的服务会遗漏零实例停止情形。销毁时清掉失败的清理记录，会把尚未解决的后端资源误报为已停稳。

## Consequences

自定义终端组合必须挂载共享所有权插件。目录只存在于进程内，不能替代持久 Goal 恢复。直接测试覆盖延后挂载、多实例、外部所有者、清理失败保留，以及再次排空导致的批量恢复失效；产品冷重启验收仍是独立检查。
