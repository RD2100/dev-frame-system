# 记忆库 UI 优化计划 v3

## 背景
当前记忆库弹窗界面简陋，信息密度低，缺少管理操作按钮，视觉上与专家模式风格不统一。用户要求参考 Obsidian、Notion、专家模式等成熟产品进行优化。

## 当前问题（对照截图）

1. **信息密度太低**：每张卡片只有图标 + "无标题" + 日期，看不到实际内容摘要
2. **缺少类型标签**：没有区分"事实"和"偏好"的视觉标识
3. **缺少实体标签**：entities 字段没有展示
4. **卡片尺寸太小**：210px 宽但内容太少，显得空荡
5. **没有 hover 效果**：交互反馈不明确
6. **缺少管理操作**：卡片上没有编辑/删除/打开文件等操作按钮
7. **没有筛选/排序**：不能按类型/时间筛选
8. **预览面板太简陋**：右侧预览只有纯文本，没有 markdown 渲染

## 优化目标

参考专家模式（ExpertTeamCard）的设计语言，结合 Obsidian/Notion 的笔记管理理念，打造一个视觉精美、功能完整的记忆管理界面。

## 设计方案

### 1. 整体布局
- **弹窗尺寸**：从当前的小弹窗扩大到 `min(960px, calc(100vw - 48px))` × `min(640px, calc(100vh - 48px))`，参考专家模式的 1120×820 比例
- **三栏布局**：
  - 左栏（240px）：分类侧边栏（全部/事实/偏好/按实体分组）
  - 中栏（自适应）：卡片网格
  - 右栏（320px）：预览面板（选中卡片时展开）

### 2. 卡片设计（参考专家模式 ExpertCard）

每张卡片包含：
- **顶部行**：类型标签（事实/偏好）+ 实体标签
- **标题**：粗体，显示笔记标题（从文件名提取）
- **摘要**：2-3 行正文摘要，截断显示
- **底部元信息**：日期 + 文件名

卡片样式：
- min-height: 140px
- border: 0.5px solid var(--dsw-alias-border-l3)
- border-radius: 14px
- background: var(--dsw-alias-bg-layer-1)
- hover: border-color 变为 brand-primary，background 变为 layer-2
- 选中状态：与 hover 一致

### 3. 管理操作按钮

每张卡片 hover 时显示操作按钮：
- **复制路径**：复制绝对路径到剪贴板（现有 API 已支持）
- **引用到对话**：插入到当前对话草稿（现有 API 已支持）

预览面板底部增加：
- **编辑**：（只读模式下禁用，tooltip 说明）
- **删除**：（只读模式下禁用，tooltip 说明）

### 4. 筛选与排序

顶部工具栏：
- **筛选 tabs**：全部 / 事实 / 偏好（参考专家模式的 centerTabs）
- **排序**：按时间排序（最新优先 / 最旧优先）
- **搜索**：保留现有搜索框

### 5. 空态设计

- 带图标的友好空态
- 说明文字："还没有记忆笔记，AI 会自动记录你的偏好和重要事实"
- 引导提示

## 技术实现

### Host 端改动
**无改动**——现有 API 已经返回 kind/createdAt/entities/summary 字段。

### Client 端改动

#### 1. LibraryCard.tsx
- 重构 LibraryPane 为三栏布局
- 新增左侧分类侧边栏组件
- 新增卡片 hover 操作按钮
- 新增筛选 tabs 状态管理
- 新增排序逻辑

#### 2. LibraryCard.module.css
- 重写所有样式，对齐专家模式设计语言
- 使用 CSS 变量：var(--dsw-alias-*)
- 卡片网格：repeat(auto-fill, minmax(260px, 1fr))
- 左侧侧边栏样式
- hover/selected 状态样式

#### 3. locales.ts
- 新增筛选/排序/操作按钮相关的双语 key

## 验收标准

1. 卡片显示类型标签（事实/偏好）+ 标题 + 摘要 + 日期 + 实体标签
2. 卡片 hover 时显示操作按钮（复制路径/引用到对话）
3. 顶部有筛选 tabs（全部/事实/偏好）
4. 视觉风格与专家模式一致（圆角/边框/hover 效果）
5. 空态友好
6. 刷新后数据正确加载
7. `pnpm run typecheck` 全绿
8. `pnpm run lint` 全绿
9. client 单测全绿

## 测试方案

### Client 测试清单
- 卡片网格渲染：验证 kind/entities/summary 字段正确显示
- 筛选 tabs：点击"事实"只显示 fact 类型卡片，"偏好"只显示 preference 类型
- 排序逻辑：按 mtimeMs 降序排列
- hover 操作按钮：hover 时显示复制路径/引用按钮
- 空态：files.length=0 时显示空态组件
- UNAVAILABLE 态：status=UNAVAILABLE 时显示不可用提示
- 预览面板：点击卡片展开右侧预览，显示文件内容和操作按钮

## 范围排除

- 不做编辑/删除功能（只读 Vault 限制）
- 不做新建笔记功能
- 不做 markdown 渲染（保持纯文本预览）
- 不做最近访问/Vault 选择 UI
