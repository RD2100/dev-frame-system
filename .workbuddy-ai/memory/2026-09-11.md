# 2026-09-11 DSH 桌面启动服务

## 本次解决的两个真实 bug（截图报错："守护器已启动，但服务在 90 秒内未就绪"）

### 1. PID 回收导致误判"守护器还活着"（主因）
- 状态文件 `C:\Users\25313\.dsh\dsh-web-supervisor.json` 记录 `supervisorPid: 3244`。
- 该守护器 node 进程早已退出，Windows 把 PID 3244 回收给了 `RuntimeBroker.exe`。
- 旧启动脚本用 `Get-Process -Id` 仅判断"PID 存在" → 判为存活 → 不启动新守护器 → 干等 90 秒超时。
- **修复**：新增 `Get-SupervisorProcess()`，要求 PID 存在 **且** 进程名是 node **且** 命令行含 `dsh-web-supervisor.mjs`。
- 判为失效时，删除陈旧的 `dsh-web-supervisor.json` + `.lock` 再启动，避免新守护器抢不到单例锁。

### 2. 错误弹窗被 codex 联网噪音淹没
- stderr 里有 82 行 `codex_models_manager: failed to refresh available models: timeout waiting for child process to exit`，
  以及 `codex_api::... wss://chatgpt.com/backend-api/... tls handshake eof`、`rmcp::` — 均为外网不可达，与启动无关。
- **修复**：
  - `dsh-web-supervisor.mjs` 的 `pipeLines()` 写入前用 `NOISE = /codex_models_manager|codex_api::|rmcp::/` 过滤，不再落盘。
  - 启动脚本 `Get-ErrorTail()` 同样过滤，并优先展示**守护器日志**（信息量远高于服务 stderr）。
  - 新增失败快速退出：刚启动的守护器进程若自行退出，立刻报错，不耗完 90 秒。

### 3. 加固：守护器脱离控制台（针对"频繁中断"）
- `Start-Process` 启动的 node 仍附着在启动脚本的控制台上；控制台关闭时 Windows 广播 `CTRL_CLOSE_EVENT` 会把守护器一起带走。
- **修复**：新增 `Start-DetachedNode()`，用 P/Invoke `CreateProcess` + `DETACHED_PROCESS|CREATE_NEW_PROCESS_GROUP` 启动，
  顺便传 `lpEnvironment = IntPtr.Zero` 继承环境，**彻底绕开 HTTP_PROXY/http_proxy 大小写重复导致的 Start-Process 崩溃**。
- 三级降级：P/Invoke → `Start-Process` → 抛错。语法已用 `Parser::ParseFile` 校验通过（SYNTAX OK）。

## 环境限制（重要，避免重复踩坑）
- **本会话无法持久化后台进程**：Bash 的 `nohup ... &` 在工具调用结束时被回收（实测 supervisor 起来 10 秒就没了）。
- **PowerShell 工具沙箱拦截 node**：`Start-Process node --version` 输出为空、`$LASTEXITCODE` 为 null；探测脚本 `dsh-probe.txt` 已证实。
- **`Add-Type` 被工具安全策略阻断**（"Command blocked for security"）。用户双击时是普通 PowerShell，不受影响；
  但在本会话内无法运行时验证 `Add-Type -TypeDefinition`。
- 因此：**服务只能由用户双击桌面图标 / 登录自启 .bat 启动**，我这边无法代劳。

## 关键路径
- 桌面脚本：`C:\Users\25313\Desktop\DSH 启动服务.ps1`（备份 `.ps1.bak`、`.ps1.bak.20260910-1119`）
- 守护器：`C:\Users\25313\.dsh\bin\dsh-web-supervisor.mjs`

## 服务健康判据
- `dsh-web-supervisor.json` 中 `status == "running"` 且 `url` 非空，且 `childPid` = 3080 的 LISTENING 属主 PID。
- 正常启动耗时约 10 秒（`child ready pid=... url=http://127.0.0.1:3080/?token=...`）。
- 注意：curl 必须加 `--noproxy '*'`，否则走代理返回 502。
