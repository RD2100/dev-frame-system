# 验收检查单

编写 PRD 的验收标准、把它们分解成任务级验收标准、或在交接与测试前核查其可测试性时，使用本技能。核查结论只有三种：通过、不通过、无法判断；不允许静默放过任何一项。

## 使用步骤

1. 完整阅读 [references/checklist.md](references/checklist.md)，按被审产物类型（PRD 验收标准 / 任务验收标准 / 测试映射）选取适用的条目组；不适用整个条目组时说明原因。
2. 逐项核查。每项给出一行依据，指向被审产物的具体条目或小节；没有依据的项按无法判断处理。
3. 汇总结论：不通过项整理为改写要求；无法判断项全部进入产物的开放问题。
4. 结论放在最后，形如：可接受 / 需改写（列出条目与改法）/ 建议退回（列出理由）。

## 边界

- 本检查单核查标准的可判定性与边界，不替代领域判断："优先级怎么排"这类问题给出证据与倾向，决定留给人类关口。
- 评审对象是标准文本与其可追溯性；评审方不承诺标准在实现后必然可自动化，自动化可行性缺口由测试阶段的测试计划兜底，并应出现在开放问题中。
