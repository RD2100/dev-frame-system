# 代码评审检查清单

## 代码质量
- [ ] 命名清晰：变量、函数、类名表达意图
- [ ] 函数精简：单函数不超过 50 行
- [ ] 无重复代码：DRY 原则
- [ ] 错误处理：所有可能失败的操作都有对应处理

## 安全性
- [ ] 输入验证：所有外部输入都经过校验
- [ ] 敏感数据：密钥、密码、token 不出现在代码或日志中
- [ ] 权限检查：敏感操作前验证权限
- [ ] 注入防护：SQL、命令、XSS 注入向量已处理

## 可维护性
- [ ] 文档充分：公共接口有 JSDoc/注释
- [ ] 日志合理：关键操作有日志，无敏感信息
- [ ] 配置外化：硬编码值已移到配置
- [ ] 依赖清晰：无未使用的依赖

## 性能
- [ ] 无明显的性能瓶颈
- [ ] 资源正确释放：文件句柄、连接、内存
- [ ] 缓存合理：重复计算有缓存

## 测试
- [ ] 单元测试覆盖核心逻辑
- [ ] 边界条件已测试
- [ ] 错误路径已测试
