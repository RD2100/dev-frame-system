# 代码评审检查清单参考

本文件是 `code-review-checklist` skill 的参考文档，定义了代码评审的五个维度及其检查项。

## 使用方式

code-reviewer 专家在评审实现时，按本清单逐项核对，将结果写入 review.md 的对应维度。

## 检查项

### 代码质量
| 检查项 | 说明 |
|--------|------|
| 命名清晰 | 变量、函数、类名表达意图 |
| 函数精简 | 单函数不超过 50 行 |
| 无重复代码 | DRY 原则 |
| 错误处理 | 所有可能失败的操作都有对应处理 |

### 安全性
| 检查项 | 说明 |
|--------|------|
| 输入验证 | 所有外部输入都经过校验 |
| 敏感数据 | 密钥、密码、token 不出现在代码或日志中 |
| 权限检查 | 敏感操作前验证权限 |
| 注入防护 | SQL、命令、XSS 注入向量已处理 |

### 可维护性
| 检查项 | 说明 |
|--------|------|
| 文档充分 | 公共接口有 JSDoc/注释 |
| 日志合理 | 关键操作有日志，无敏感信息 |
| 配置外化 | 硬编码值已移到配置 |
| 依赖清晰 | 无未使用的依赖 |

### 性能
| 检查项 | 说明 |
|--------|------|
| 无瓶颈 | 无明显性能瓶颈 |
| 资源释放 | 文件句柄、连接、内存正确释放 |
| 缓存合理 | 重复计算有缓存 |

### 测试
| 检查项 | 说明 |
|--------|------|
| 单元测试 | 核心逻辑有单元测试 |
| 边界条件 | 边界条件已测试 |
| 错误路径 | 错误路径已测试 |
