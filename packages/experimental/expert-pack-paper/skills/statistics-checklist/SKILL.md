# 统计严谨性检查单

审稿人核查论文统计严谨性时使用本技能：以 method.md 事先声明的统计方案为基准，审查执行与写作是否守约。核查结论只有三种：通过、不通过、无法判断；不允许静默放过任何一项。

## 使用步骤

1. 完整阅读 [references/checklist.md](references/checklist.md)，四组条目逐组核查；整组不适用时说明原因，不整组跳过。
2. 逐项核查。每项给出一行依据，指向 method.md 的哪条声明、experiments.md 的哪条记录或 draft.md 的具体位置；没有依据的项按无法判断处理。
3. 汇总结论：不通过项整理为审稿意见（major 或 minor）；无法判断项全部进入 openQuestions；"感觉可疑"但核对不了的按无法判断处理，不定罪。
4. 检查单不覆盖的统计问题直说"超出检查单"，单独开意见，不硬套条目。

## 边界

- 本检查单核查统计纪律，不替代领域判断："效应量是否有实际意义"给出证据与倾向，分量判断留给作者与人类终审。
- 评审对象是论文与实验记录的文本；本检查单不重跑实验，也不验证原始数据，该缺口由执行侧与人类终审兜底，核对不了的项应出现在审稿意见的 openQuestions 中。
