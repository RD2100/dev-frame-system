# 统计严谨性检查单

按组核查；每项的结论是"通过 / 不通过 / 无法判断"之一，并附一行依据（指向 method.md 的声明、experiments.md 的记录或 draft.md 的具体位置）。

## 通用条目

- [ ] 核对基准是 method.md 事先声明的统计方案，不是审稿人的事后偏好；设计未声明的统计决策按设计缺陷处理，而不是默认通过。
- [ ] 每条结论都指向可核对的位置：method.md 的哪一条声明、experiments.md 的哪条记录、draft.md 的哪一节。

## 统计效力

- [ ] 样本量与随机种子数达到 method.md 的声明；设计未声明样本量与种子数的，标注为设计缺陷并给补救建议。
- [ ] 主指标报告了效应量与区间估计（如可得），不是只报 p 值。
- [ ] 所用检验的前提条件（独立性、分布假设等）与数据形态匹配，不匹配处有说明。
- [ ] 效力不足时的结论措辞已收敛："未检测到差异"没有被写成"不存在差异"。

## 基线公平性

- [ ] 基线配置与原报告一致；重调超参的基线有标注，未重调的基线没有吃亏。
- [ ] 基线与所提方法使用同一数据划分与同一评测协议。
- [ ] 综述中最强方法被用作基线，或其缺位有说明；没有稻草人基线。
- [ ] 基线与所提方法的运行环境与资源约束可比；不可比处有说明。

## 多次比较校正

- [ ] 被检验的指标×数据集×对照组合全部清点，与 method.md 的声明一致；漏报的组合被找出来。
- [ ] 声明的校正方法被实际执行，执行方式与声明一致。
- [ ] 事后新增的比较被标注为事后，没有混入事前声明的主张。
- [ ] 校正后的显著性结论与正文主张的强度一致；没校正的多重主张没有被写成"显著"。

## 数据泄漏

- [ ] 评测集与训练集无重叠，划分方式可核对。
- [ ] 预处理与特征选择没有使用测试折或评测集的信息。
- [ ] 超参调优没有在最终评测集上进行。
- [ ] 时间序列或流式数据的时间边界没有被跨越；给不出排除证据的按风险列出并说明核实路径。

## 选择性报告与诚实边界

- [ ] experiments.md 的失败与偏离记录在论文中被如实承接，没有被藏进措辞。
- [ ] 没有"只报有利种子、有利指标"或事后换指标的信号。
- [ ] inconclusive 的结果没有被写成支持性主张。
- [ ] 修辞性强调（"显著提升"）与统计实际（效应量、校正后 p 值）匹配。
