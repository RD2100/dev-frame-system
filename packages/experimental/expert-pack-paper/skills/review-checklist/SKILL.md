# 审稿检查单

对一份研究产物做结构化评审时使用本技能：上游阶段产物到达时的 handoff 核查、人类关口驳回后的修订自查、以及交付前的最终自查。核查结论只有三种：通过、不通过、无法判断；不允许静默放过任何一项。

## 使用步骤

1. 完整阅读 [references/checklist.md](references/checklist.md)，按被审产物类型选取适用的条目组；不适用整个条目组时说明原因。
2. 逐项核查。每项给出一行依据，指向被审产物的具体小节、引用键或字段；没有依据的项按无法判断处理。
3. 汇总结论：不通过项整理为修订要求；无法判断项全部进入产物的开放问题；都不满足时，给出"退回上一阶段"的建议及理由。
4. 结论放在最后，形如：可接受 / 需修订（列出修订要求）/ 建议退回（列出理由）。

## 边界

- 本检查单核查结构与纪律，不替代领域判断："新颖性是否足够"这类问题给出证据与倾向，决定留给人类关口。
- 评审对象是产物文本与其引用键的可追溯性；评审方不承诺核验引用文献在外部世界真实存在，该缺口由后续检索、撤稿检查与人类关口兜底，并应出现在被审产物的开放问题中。
