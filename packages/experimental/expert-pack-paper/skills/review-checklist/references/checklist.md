# 审稿检查单

按产物类型选取适用的条目组；同一份产物可命中多组。每项的结论是"通过 / 不通过 / 无法判断"之一，并附一行依据（指向具体小节、引用键或字段）。

## 通用条目（任何产物）

- [ ] 产物文件存在、非空，且写入了运行目录内声明的位置。
- [ ] 产物结构符合所属专家人设"输出格式约定"中列出的全部小节。
- [ ] 每个无法确定、无法核实或需要人类决定的事项都进入了开放问题，没有静默丢弃。
- [ ] 产物没有扩大或缩小上游批准的范围；范围变更只出现在人类关口的批注之后。

## 证据与引用（综述与任何带论断的产物）

- [ ] 每条实质性论断都带引用键；无出处的论断被显式标注"未找到出处"而不是删去限定词后保留。
- [ ] 同一文献全程复用同一引用键；参考文献一节能为每个引用键提供可核对的出处信息。
- [ ] 撤稿、更正或版本冲突信号在引用处有标注；核对不了的撤稿状态被如实标注为未核对，而不是默认通过。
- [ ] 来自记忆检索的内容按其信任标签引用；`memory_changed` 或 `incomplete_note` 的内容没有被当作已验证事实。

## 视角清单（perspectives.md）

- [ ] 视角数量在 3 到 6 个之间，且偏离时附有理由。
- [ ] 每个视角都有视角名、核心问题、研究理由、与其他视角的边界四项。
- [ ] 没有两个视角只在措辞上不同；每个视角都能追溯到给定研究主题。
- [ ] 文末有覆盖度自评：覆盖了哪些切面、可能遗漏哪些、为什么停在这个数量。

## 综述（survey.md）

- [ ] 开头有综述范围：覆盖的视角、检索限制、未覆盖的内容。
- [ ] 有研究缺口（gaps）一节，按证据、方法、场景或人群、时间性分类，每条 gap 注明来源引用键。
- [ ] 开放问题一节与阶段结果的 openQuestions 一致。

## 候选研究问题（research-questions.md）

- [ ] 候选数量为 2 到 3 个，且偏离时说明了缺什么条件。
- [ ] 每个候选注明来自的 gap 与引用键，并有新颖性论证：相对综述中哪些已有工作、差异是什么。
- [ ] 每个候选的风险清单覆盖数据可得性、评测方法、基线、时间与算力、科学风险。
- [ ] 有"留给关口的问题"一节；排序建议被标注为建议而不是决定。

## 方法设计（method.md）

- [ ] 研究问题与被批准的候选逐字对应，假设为 H1/H0 形式。
- [ ] 数据集与来源给出可核对的出处与许可现状；核对不了的进开放问题。
- [ ] 基线有选取理由，且理由能支撑新颖性论证；没有稻草人基线。
- [ ] 指标、检验方法、显著性水平、多次比较的处理在设计内事先声明。
- [ ] 有消融计划与预期失败模式，以及局限与开放问题一节。

## 诚实边界（交付前最后一遍）

- [ ] 没有编造的文献、数据集、基准或数字；所有"需要进一步确认"的表述落在开放问题而不是正文断言。
- [ ] "综述未覆盖"没有被写成"没人做过"；需要外部检索确认的表述保持其不确定形态。
- [ ] 修订稿逐条回应了驳回批注；未被批注授权的范围没有被改动。
